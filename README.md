# Bitva o Británii 1940

Hra v prohlížeči o leteckých bojích nad Británií v létě 1940. Inspirovaná hrou, kterou autor hrál jako dítě, ale napsaná znovu od nuly: čeština a československé prvky (českoslovenští piloti v RAF).

## Jak hrát
Stáhněte index.html a otevřete ho v prohlížeči. Nic se neinstaluje.
